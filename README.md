## GitHub Pages 部署方式

1. 新建一个 GitHub 仓库，例如 `resume-homepage`。
2. 将主页文件上传到仓库根目录。
3. 建议把 `段怡蓉秋招个人主页.html` 重命名为 `index.html`。
4. 进入仓库 `Settings`。
5. 找到 `Pages`。
6. 在 `Build and deployment` 中选择 `Deploy from a branch`。
7. Branch 选择 `main`，目录选择 `/root`。
8. 保存后等待 GitHub Pages 生成访问链接。
